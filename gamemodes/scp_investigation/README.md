# SCP Investigation

First playable vertical slice.

- 1-3 player sandbox-based gamemode
- Three evidence objects and investigation phase
- Containment phase after evidence collection
- One server-authoritative anomaly
- Extraction phase after containment
- Bodycam toggle: F3
- Thermal view toggle: F4
- Crowbar and pistol prototype loadout
- First test map: gm_construct

Test flow: collect all three evidence objects with E, find the anomaly, damage it after containment unlocks, then return to the extraction point near spawn.

The GitHub repository is the source of truth. The GMod installation is the test target.
